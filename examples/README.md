# Examples

Prediction inputs use matching `idx/<sample>.idx` and `cmt/<sample>.cmt` files.
Evaluation adds `amt/<sample>.amt` ground truth. See
[`docs/data-format.md`](../docs/data-format.md) for exact conventions.

Dataset files are not stored directly in this Git repository. The training set
and model checkpoints are available from
[Zenodo](https://doi.org/10.5281/zenodo.22125162). This directory is kept as the
documented location for small examples that may be added in a future release.
