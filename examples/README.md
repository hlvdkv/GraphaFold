# Examples

Prediction inputs use matching `idx/<sample>.idx` and `cmt/<sample>.cmt` files.
Evaluation adds `amt/<sample>.amt` ground truth. See
[`docs/data-format.md`](../docs/data-format.md) for exact conventions.

Dataset files are not redistributed in this repository. This directory is kept
as the documented location for small, redistribution-compatible examples that
may be added in a future release.
